使用与兼容说明

1. 默认强制 WASM-CPU，即使设备提供 WebGPU 也不加载 GPU 引擎。可在「推理后端」切换 WebGPU，或关闭强制 CPU 后启用自动选择。首次下载模型需要网络与存储空间。

2. 输入需求或上传源码。代码量较大时按文件拆分任务，把接口与关键约束写进项目上下文。

3. 点击代码块的「打开」，可编辑、下载、做 JavaScript/JSON 语法检查，或隔离预览 HTML。

CPU 路线使用 q4 量化模型；大体积权重改为 OPFS 分块缓存并校验文件大小。iPad 如因内存限制自动刷新，页面会恢复未发送草稿并提示异常加载阶段。兼容模式不代表代码能力超过 7B。速度、内存和浏览器限制仍可能导致失败。CPU 模式在后台工作线程运行，停止无响应时会强制释放模型。

无需 API Key。没有按次 AI 接口费用。浏览器不提供 Python/C++/Rust 编译器；生成的测试需要另行运行。HTML 预览只运行内联内容，屏蔽网络与外部资源。

FORGE V4.3 不允许使用 file:// 直接加载模型；必须使用 localhost 或 HTTPS。电脑可在 HTML 所在目录运行 python3 -m http.server 8000，再从 http://localhost:8000 打开文件。

设置、对话、附件和代码编辑保存在此浏览器，导出可备份。运行库和模型依赖在线下载，不保证离线重开可用。
